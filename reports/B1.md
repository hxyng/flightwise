# B1 report: flight providers

**Built** (`backend/flightwise/providers/`): `mock.py`, `status.py`, `search.py`, `__init__.py` (exports `get_flight_status`, `get_departures`, `search_flights`, `provider_names`), plus `backend/tests/test_providers.py` (11 tests, passing; the AA 100 one-liner prints a FlightStatus).

- Mock status is anchored to the first time a (flight, date) is seen in the process: 70% depart 5-40 min later, 30% already in progress. Phases run scheduled, boarding (last 30 min), departed, en_route, landed, with `progress` 0..1. About 1 in 3 flights get a +15/30/45 min delay and/or gate change 30-100 s after first sight. Deterministic per (flight, date) except for the clock anchor. Tests patch `mock._now`; `mock.reset()` clears anchors.
- Mock search: 5-8 offers, 0-1 stops, prices and durations from great-circle distance, works for any airport codes. 16 airports, 8 airlines.
- Real paths: any exception (HTTP error, 8 s timeout, empty or unparsable body) logs a warning and returns mock (the `source` field says "mock"). `FLIGHTWISE_MOCK=1` skips all network.

**Plugging in keys:** set `AERODATABOX_KEY` (and `AERODATABOX_URL` if API.market's base differs) and `SERPAPI_KEY` in `ROOT/.env`. Check `provider_names()` or the logs for "failed ... using mock" warnings.

**Could NOT verify (no live keys or network calls made):**
- API.market auth header: I send `x-api-market-key`. This is from memory; the research report says it is unknown. If the real call 401s, change `_client()` in `status.py`.
- AeroDataBox response shape (`departure/arrival.scheduledTime.utc`, `revisedTime`, `runwayTime`, `status` enum values) and the airport-board item shape (`movement` = far-end airport). Parsing is defensive and tolerant of older `scheduledTimeUtc` names, but only tested against hand-written fixtures. Departures query param names are also unverified.
- SerpApi `google_flights` parsing was tested against the doc example shape only. Times are local airport times with no zone; I tag them UTC, so durations come from `total_duration` when present.
- Premise note: no premise was found false beyond those already flagged in the research reports. models.py and config.py are fine as is.
